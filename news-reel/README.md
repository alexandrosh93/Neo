# ΠΑΣΑ στα ΝΕΑ – News Reel

Κάθετο reel (1080x1920, 9:16) για τα νέα του κυπριακού ποδοσφαίρου, με ελληνικό voiceover
και υπότιτλους συγχρονισμένους λέξη-λέξη.

```bash
pip install pillow edge-tts pyworld     # + ffmpeg
python3 build.py script.json reel.mp4
```

- **Φωνή:** Microsoft Neural `el-GR-NestorasNeural` (ανδρική) μέσω edge-tts — χρειάζεται πρόσβαση στο
  `speech.platform.bing.com`. Αν δεν υπάρχει, πέφτει σε offline espeak-ng/MBROLA (robotic).
  Αλλάζεις φωνή/ταχύτητα με `voice` / `rate` στο `script.json`.
- **Νέα επεισόδια:** άλλαξε τα `stories` στο `script.json`:
  - `tag` – π.χ. `05 / ΕΥΡΩΠΗ`
  - `headline` – 2 γραμμές, ό,τι είναι σε `[αγκύλες]` βγαίνει κίτρινο
  - `body` – το κείμενο στο χαρτί
  - `image` – (προαιρετικά) φωτογραφία, π.χ. `photos/1.jpg`· μπαίνει σε κάδρο με zoom και τότε το `body` δεν εμφανίζεται
  - `voice` – τι εκφωνείται (γράψε αριθμούς/ώρες ολογράφως για σωστή προφορά)
- **Hook:** (προαιρετικό) `hook` στο `script.json` — full-screen φωτογραφία + τεράστιος τίτλος από το 1ο frame, φωνή από 0", πριν το intro. Πεδία: `tag`, `headline`, `image`, `voice`, `size`.
- **Intro:** `start` κόβει τα πρώτα δευτερόλεπτα του clip.
- **Intro (συνέχεια):** `intro.video` (assets/intro.mp4) παίζει πρώτο· η φωνή ξεκινά στο `voice_at` (δευτ.) και η μουσική χαμηλώνει στο `music_volume`.
- Στο τέλος εμφανίζεται recap με όλα τα θέματα (σαν το poster).
- `assets/logo.png` – λογότυπο footer, `assets/fonts/` – Fira Sans Extra Condensed (SIL OFL).

## Προφορά (pronunciations.json)

Λεξικό για το πώς λέει η φωνή συντομογραφίες/ονόματα. Αριστερά όπως γράφεται (έτσι φαίνεται και στους
υπότιτλους), δεξιά όπως εκφωνείται. Εφαρμόζεται αυτόματα σε κάθε reel.

```json
{ "ΓΣΠ": "Γα Σι Πι" }
```

## Ερωτήσεις

- **Αποφεύγουμε ερωτήσεις στο `voice`.** Η φωνή δεν τις αποδίδει σωστά, ακόμα και με την επεξεργασία τόνου.
  Τις γράφουμε ως δήλωση ή θαυμαστικό: «Και τον έριξε ο Ολυμπιακός!» αντί «Ξέρεις ποιος το έριξε;».
- Ερωτήσεις για engagement («Ποιος κερδίζει αύριο;») μπαίνουν μόνο στο caption της ανάρτησης.
- (Αν ποτέ χρειαστεί ερώτηση, το build ανεβάζει αυτόματα τον τόνο στην τελευταία λέξη με pyworld.)

## Φωνή (Azure)

Στο `script.json`:
- `"engine": "azure"` – επίσημο Azure AI Speech (δωρεάν F0, 500.000 χαρακτήρες/μήνα), resource `kouponaki-tts`, `"region": "northeurope"`.
  Στο cloud session το κλειδί το βάζει αυτόματα ο proxy· τοπικά όρισε `AZURE_SPEECH_KEY`.
- `"voice"`: `el-GR-NestorasNeural` (rate `+11%`) ή `de-DE-FlorianMultilingualNeural` (rate `+0%`).
- Κάθε πρόταση συντίθεται χωριστά με φυσικές παύσεις· οι ερωτήσεις παίρνουν ανοδικό τόνο (pyworld).
- Αν το Azure αποτύχει, πέφτει αυτόματα σε edge-tts (Νέστορας, `edge_rate`).

## Κανόνες για το κείμενο της φωνής (`voice`)

- Κόμμα μόνο εκεί που ένας άνθρωπος θα ανέπνεε· όχι κόμματα «γραμματικής» που κόβουν τη ροή.
- Σύντομες προτάσεις (έως ~15 λέξεις). Οι παύσεις μπαίνουν αυτόματα: ~270ms μετά από «!», ~320ms μετά
  από «.», ~450ms μετά από ερώτηση, ενώ οι παύσεις στα κόμματα κόβονται στα 260ms το πολύ.
- Σκορ/ώρες/αριθμοί ολογράφως («ένα μηδέν», «στις επτά»).
- Φωτογραφίες: καθαρές, full-width, χωρίς περίγραμμα.

## Τέλος: follow pop-up (όπως στο «Ήξερες ότι;»)

Στο τέλος, πάνω από το recap, μόλις η φωνή πει «φόλοου»:
- Η κάρτα προφίλ του kouponaki (avatar με κόκκινο «+», όνομα, «Για περισσότερα «ΠΑΣΑ στα ΝΕΑ»») πετάγεται με ήχο.
- Ένα χεράκι πατάει «ΚΑΝΕ FOLLOW», που γίνεται «✓ FOLLOWING» με ήχο ειδοποίησης.
- Σπίθες, κομφετί, emoji και καμπανάκι που χτυπάει.
- Αν το `outro.voice` δεν λέει «φόλοου», προστίθεται αυτόματα «Κάνε φόλοου για να μη χάνεις τίποτα!».
- Ρυθμίσεις στο `"follow"`: `enabled`, `name`, `sub`, `button`, `following`, `y`.
